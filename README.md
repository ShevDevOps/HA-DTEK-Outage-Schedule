# ⚡ Інтеграція Графіка Відключень ДТЕК для Home Assistant

Даний проєкт є кастомною інтеграцією та Lovelace-карткою для системи розумного будинку Home Assistant. Він дозволяє автоматично отримувати, парсити та зручно візуалізувати графіки стабілізаційних відключень електроенергії від операторів систем розподілу ДТЕК (Київські, Київські регіональні та Одеські електромережі).

---

## ✨ Основні можливості

- **Автоматичний обхід захисту (WAF):** Використання безголового браузера (Playwright) та бібліотеки `curl_cffi` для успішного проходження перевірок сайту ДТЕК та отримання актуальних токенів сесії й кук.
- **Графічне налаштування (Config Flow):** Повністю інтерактивне покрокове додавання інтеграції через інтерфейс Home Assistant із динамічними випадаючими списками (вибір регіону, міста, пошук вулиці та вибір будинку).
- **Ефективне керування запитами:** Бекенд побудований на базі `DataUpdateCoordinator`, що оновлює дані кожні 15 хвилин та оптимізує запити до API (debouncing), запобігаючи блокуванню за IP.
- **Сучасна Lovelace-картка:** Кастомний фронтенд-елемент (`dtek-outage-card`), розроблений на фреймворку Lit (TypeScript), що відображає добову сітку тайм-слотів на сьогодні та завтра з кольоровою градацією статусів (Є світло / Немає світла / Можливе відключення).
- **Надійність та тестування:** Код покритий автоматичними Unit-тестами за допомогою `pytest` та `pytest-homeassistant-custom-component` із використанням Mock-об'єктів для ізольованої перевірки платформи сутностей.

## 🚀 Встановлення

### Варіант 1: Через HACS (Як кастомний репозиторій)
1. Переконайтеся, що у вашому Home Assistant встановлено **HACS**.
2. Перейдіть до розділу **HACS** -> **Інтеграції** (Integrations).
3. У правому верхньому куті натисніть на три крапки та виберіть **Кастомні репозиторії** (Custom repositories).
4. У полі **URL** вставте посилання на цей GitHub-репозиторій.
5. У випадаючому списку **Категорія** виберіть **Інтеграція** (Integration) та натисніть **Додати**.
6. Перезапустіть Home Assistant.

### Варіант 2: Ручне встановлення
1. Скопіюйте папку `custom_components/dtek_outage` у директорію `config/custom_components/` вашого сервера Home Assistant.
2. Скопіюйте файл `www/dtek-outage-card.js` у папку `config/www/`.
3. Перезапустіть Home Assistant.

## ⚙️ Налаштування та підключення

### 1. Додавання інтеграції
1. Перейдіть у **Налаштування** -> **Пристрої та сервіси** -> **Додати інтеграцію**.
2. Знайдіть у пошуку **DTEK Outage Schedule**.
3. Дотримуйтесь інструкцій на екрані: виберіть ваш обленерго (Київ, Область, Одеса), вкажіть місто, знайдіть вулицю та виберіть номер будинку.
4. Після завершення в системі з'явиться новий пристрій із двома сенсорами.

### 2. Реєстрація Lovelace-картки в системі
Якщо ви встановлювали плагін вручну або хочете переконатися, що картка зареєстрована:
1. Перейдіть у **Налаштування** -> **Панелі керування** -> **Ресурси** (три крапки вгорі).
2. Натисніть **Додати ресурс**.
3. Вкажіть **URL**: `/local/dtek-outage-card.js` та **Тип ресурсу**: `Модуль JavaScript`.
4. Оновіть сторінку браузера через `Ctrl + F5`.

### 3. Додавання картки на Дашборд
Натисніть "Редагувати" на вашому дашборді, додайте нову картку типу **Вручну (Manual)** та пропишіть конфігурацію:

type: custom:dtek-outage-card
autodetect: true

*Примітка: Завдяки параметру `autodetect: true` картка автоматично знайде сутність розкладу в системі. Якщо у вас додано кілька адрес, вкажіть сутність явно через параметр `entity: sensor.dtek_schedule_[ваша_адреса]`.*
